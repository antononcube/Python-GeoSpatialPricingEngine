## Distance correlation plots

```
%%chat -i=python
I have a data frame with Geo-coordinates and travel distances. I want to plot the correlation between over-the-air distances and travel distances.
Use a popular package for computing the over-the-air distances. (For example, "scikit-learn" has "haversine" distance.)
Square plot -- the ranges of the distances should be the same on the plot.
Convert the over-the-air distances to miles.
Have grid lines on the plot.
Make the plot dark mode.
```
